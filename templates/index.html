THE IDEA

Designed around a simple process

The project explores a digital alternative to relying only on manual record checks.

01

Unique QR credentials

A QR code can link to a unique, non-descriptive token rather than displaying personal details in the code itself.

02

Record-based checks

Authorised checks can compare a token with a student record and its current status.

03

Traceable activity

Verification events can be recorded to support review and accountability by authorised personnel.
